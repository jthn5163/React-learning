CHAPTER 2: PROFESSIONAL FOLDER ARCHITECTURE
================================================================================
In commercial tech companies, professional codebases follow standard layout 
conventions:

src/
├── assets/          -> Images, SVG icons, fonts, audio files
├── components/      -> Reusable UI bricks (Button, Navbar, Modal, Card)
├── pages/           -> Full route screens (Home, About, Dashboard, ProjectView)
├── data/            -> Static JSON data or mock lists
├── hooks/           -> Custom reusable React hooks
├── styles/          -> Global stylesheets and CSS variable tokens
├── App.jsx          -> Main route configuration and layout shell
└── main.jsx         -> React entry point

Golden Rule: Keep components small and focused! If a file exceeds 150 lines, 
break sub-sections into child components.

CHAPTER 4: GIT & GITHUB CRASH COURSE
================================================================================
Git is the industry standard version control system. GitHub is the cloud 
platform where developers store and share their repositories.

Step 1: Initialize Git in your project folder (in terminal):
  git init

Step 2: Check status of your files:
  git status

Step 3: Stage all files for a snapshot:
  git add .

Step 4: Commit the snapshot with a message:
  git commit -m "feat: complete initial capstone app build"

Step 5: Link to your GitHub account:
  1. Go to https://github.com and sign up / log in.
  2. Click "New Repository", name it `my-react-capstone`, and choose "Public".
  3. Copy the 3 commands GitHub shows you and paste them in your terminal:
     git branch -M main
     git remote add origin https://github.com/YOUR_USERNAME/my-react-capstone.git
     git push -u origin main

Your code is now safely backed up in the cloud!

CHAPTER 5: THE PRODUCTION BUILD
================================================================================
During development, Vite serves unminified files so you can debug easily.
When ready to publish to the world, run:

  npm run build

What this command does:
1. Compiles all JSX and modern JavaScript into ultra-fast, minified JS.
2. Purges unused CSS rules and shrinks file sizes.
3. Outputs everything into a clean `dist/` folder ready to be served anywhere!

You can test how your production build runs locally by typing:
  npm run preview

CHAPTER 6: 1-CLICK FREE DEPLOYMENT WITH VERCEL
================================================================================
Vercel is the world's premier cloud hosting platform for modern web applications.
Best of all: it is 100% FREE for student projects!

Deployment in 4 Easy Steps:
1. Go to https://vercel.com and click "Sign Up" with your GitHub account.
2. In your Vercel Dashboard, click "Add New..." -> "Project".
3. Vercel will list your GitHub repositories. Find `my-react-capstone` and click 
   "Import".
4. Keep the default settings (Vercel automatically detects Vite!) and click 
   "Deploy".

Within 30 seconds, Vercel gives you a LIVE public URL:
  https://my-react-capstone.vercel.app

Anyone with an internet connection anywhere on earth can now use your app!
