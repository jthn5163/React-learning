CHAPTER 2: VARIABLES — LET VS CONST
================================================================================
In old JavaScript, developers used `var`. `var` had confusing scoping rules 
that caused bugs. Today:
- `const`: For values that will NEVER be reassigned (Use this by default!)
- `let`: For values that WILL change over time (e.g. counters, loop variables)

Examples:
  const schoolName = "St. Xavier's Higher Secondary";
  // schoolName = "Other School"; // ERROR: Assignment to constant variable!

  let score = 85;
  score = 92; // Perfectly valid!

RULE: Always use `const`. Only switch to `let` if you know the value must change.

CHAPTER 3: ARROW FUNCTIONS
================================================================================
Traditional Function:
  function calculateTotal(price, tax) {
    return price + tax;
  }

Modern Arrow Function:
  const calculateTotal = (price, tax) => {
    return price + tax;
  };

Concise Arrow Function (Implicit Return):
If your function only does one thing, you can drop the curly braces and `return`:
  const calculateTotal = (price, tax) => price + tax;
  const square = (x) => x * x;

Why React loves arrow functions:
In React, we pass functions as event handlers:
  <button onClick={() => alert("Button clicked!")}>Click</button>

CHAPTER 4: TEMPLATE LITERALS
================================================================================
No more messy string concatenation with `+` signs!
Use backticks ( ` ` ) and `${expression}`:

Old Way:
  const student = "Rohan";
  const mark = 94;
  console.log("Student " + student + " scored " + mark + "% on the exam.");

Modern Way:
  console.log(`Student ${student} scored ${mark}% on the exam.`);

You can even run calculations inside:
  console.log(`Total after 18% GST: Rs. ${price * 1.18}`);

CHAPTER 5: DESTRUCTURING (OBJECTS & ARRAYS)
================================================================================
Destructuring unpacks values from objects or arrays into distinct variables.

1. Object Destructuring (You will use this every day in React Props):
  const student = {
    name: "Ananya",
    stream: "Computer Science",
    grade: "12th",
    physicsMark: 98
  };

  // Old way:
  // const name = student.name;
  // const stream = student.stream;

  // Modern Destructuring:
  const { name, stream, physicsMark } = student;
  console.log(`${name} is in ${stream}`);

2. Array Destructuring (You will use this in React useState hook):
  const colors = ["#ef4444", "#3b82f6", "#10b981"];
  const [primaryColor, secondaryColor] = colors;
  console.log(primaryColor); // Output: "#ef4444"

CHAPTER 6: THE TWO KINGS OF ARRAYS: .map() AND .filter()
================================================================================
In React, you NEVER use `for` loops to display items on screen. 
You use `.map()` and `.filter()`.

1. Array.map() — Transforms every item into something new:
  Syntax: array.map((currentValue, index, originalArray) => { ... })
  
  What it does: It loops over every item in your array, runs a function on that item, 
  and puts the returned value into a BRAND NEW array. The original array is unchanged.

  Example 1: Mathematical transformations
  const numbers = [2, 4, 6, 8];
  const doubled = numbers.map(num => num * 2);
  // numbers is still [2, 4, 6, 8]
  // doubled is [4, 8, 12, 16]

  Example 2: Extracting data from objects (Common in React!)
  const users = [{id: 1, name: "Ali"}, {id: 2, name: "Sara"}];
  const namesOnly = users.map(user => user.name);
  // Result: ["Ali", "Sara"]

  In React, .map() is essential to transform data into HTML/JSX elements:
  const names = ["Rohan", "Priya", "Rahul"];
  const listItems = names.map(name => `<li>${name}</li>`);

2. Array.filter() — Filters items based on a True/False condition:
  Syntax: array.filter((currentValue, index, originalArray) => { ... })

  What it does: It loops over every item and runs a condition check. If the function 
  returns `true`, the item is KEPT in the new array. If `false`, it is DISCARDED. 
  The original array is completely untouched.

  Example 1: Filtering simple numbers
  const scores = [45, 88, 72, 95, 33, 91];
  const topScores = scores.filter(score => score >= 80);
  // scores is still [45, 88, 72, 95, 33, 91]
  // topScores is [88, 95, 91]

  Example 2: Filtering objects (Common in search/filter features!)
  const products = [
    { name: "Laptop", inStock: true },
    { name: "Mouse", inStock: false },
    { name: "Keyboard", inStock: true }
  ];
  const availableProducts = products.filter(product => product.inStock === true);
  // Result: [{name: "Laptop", inStock: true}, {name: "Keyboard", inStock: true}]

Both `.map()` and `.filter()` do NOT modify the original array. 
They return a brand new array! (This concept is called Immutability, which is a core principle in React).

CHAPTER 7: THE SPREAD OPERATOR (...)
================================================================================
The three dots `...` unpack items from an array or object.

1. Spreading Arrays:
  const boys = ["Karan", "Vivek"];
  const girls = ["Sneha", "Divya"];
  const allStudents = [...boys, ...girls, "Teacher"];
  // Result: ["Karan", "Vivek", "Sneha", "Divya", "Teacher"]

2. Copying and Updating Objects (Crucial for React State):
  const originalProfile = { name: "Aditi", role: "Junior Dev", points: 100 };
  const updatedProfile = { ...originalProfile, points: 150 };
  // Result: { name: "Aditi", role: "Junior Dev", points: 150 }

CHAPTER 8: ES6 MODULES (IMPORT AND EXPORT)
================================================================================
In modern JavaScript, code is split into multiple files for cleanliness.

File 1: mathHelper.js
---------------------
export const PI = 3.14159;
export const add = (a, b) => a + b;

const defaultCalculatorName = "MegaCalc 3000";
export default defaultCalculatorName;

File 2: app.js
--------------
import defaultCalculatorName, { PI, add } from './mathHelper.js';

console.log(defaultCalculatorName);
console.log(add(10, 20));

RULE: You can have multiple named exports (`export const ...`), 
but only ONE default export (`export default ...`) per file.

CHAPTER 9: WEEKLY HANDS-ON PROJECT: "HIGH-SCORER FILTER"
================================================================================
Goal: Write a JavaScript script (`marksheet.js`) that analyzes student test 
records using `.map()`, `.filter()`, and destructuring.

Code (Save as marksheet.js and run with Node or in browser console):
-------------------------------------------------------------------
const students = [
  { id: 1, name: "Aarav Sharma", mark: 92, stream: "Science" },
  { id: 2, name: "Diya Nair", mark: 76, stream: "Commerce" },
  { id: 3, name: "Kavya Patel", mark: 88, stream: "Science" },
  { id: 4, name: "Mohammed Zayd", mark: 64, stream: "Humanities" },
  { id: 5, name: "Rithvik Sen", mark: 95, stream: "Science" }
];

// Step 1: Filter students scoring >= 80% (Distinction)
const distinctionStudents = students.filter(student => student.mark >= 80);

// Step 2: Use destructuring & .map() to create formatted certificates
const certificates = distinctionStudents.map(({ name, mark, stream }) => {
  return `[CERTIFICATE OF EXCELLENCE] ${name} (${stream}) - Score: ${mark}%`;
});

// Step 3: Display results
console.log("=== DISTINCTION HONORS ROLL ===");
certificates.forEach(cert => console.log(cert));

// Step 4: Calculate Average mark using spread and reduce
const totalMarks = students.reduce((sum, s) => sum + s.mark, 0);
const classAverage = (totalMarks / students.length).toFixed(1);
console.log(`\nOverall Class Average: ${classAverage}%`);
